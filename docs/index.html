Geoprocessamento com imagens CBERS-4A/WPM e Sentinel-2

Correção atmosférica, remoção de nuvens e substituição de pixels

Autores

Danilo Roberto Fioramonte

Danilo Marques de Magalhães

Data de Publicação

26 de setembro de 2026

O presente material é um Recurso Educacional Aberto elaborado a partir dos resultados de uma etapa de pesquisa de mestrado em Geografia, na área de Sensoriamento Remoto. Você irá aprender a fazer a correção atmosférica de imagens CBERS-4A/WPM (conversão de número digital (Digital Number) para reflectância de topo de atmosfera (top-of-atmosphere) - TOA e posteriormente para reflectância de superfície - BOA); a remoção de nuvens utilizando aprendizado profundo (biblioteca OmniCloudMask) (Wright et al., 2025); e a substituição de pixels contaminados usando Sentinel-2 super-resolvido (de 10 metros para 2,5 metros de resolução espacial utilizando o modelo SEN2SR + interpolação bicúbica para 2 metros) (Aybar et al., 2026).

Cada aula contém vídeo (em breve), código comentado e duas trilhas de execução: JupyterLab (utilizando gerenciador de ambientes pixi - Recomendado) e Google Colab para quem prefere rodar em ambiente nuvem.

NotaRecomendações de instalação

A instalação local (usando pixi) é recomendada para usuários que precisam processar áreas maiores, tendo em vista que o Google Colab tem limitações de tempo de execução e de espaço em disco. A instalação local também é recomendada para quem deseja aprender a instalar e configurar ambientes Python, tendo em vista que essa é uma habilidade importante para trabalhar com dados geoespaciais.

Não é preciso ter experiência com Python, pixi ou GitHub. A Aula 00 começa do zero absoluto.

ImportanteCite também os métodos que você usar

Este material organiza e explica ferramentas de terceiros. Ao empregar os métodos das aulas, cite os trabalhos originais junto com esta obra: STAC (Radiant Earth Foundation, 2021) para aquisição de imagens via API; Brazil Data Cube (Ferreira et al., 2020) para as imagens CBERS-4A; SEN2SR (Aybar et al., 2026) para a super-resolução; OmniCloudMask (Wright et al., 2025) para a detecção de nuvens; o 6S (Vermote et al., 1997) para a correção atmosférica; o AROSICS (Scheffler et al., 2017) para o corregistro; e o Gram-Schmidt (Aiazzi; Baronti; Selva, 2007; Laben; Brower, 2000) para a fusão com a pancromática.
