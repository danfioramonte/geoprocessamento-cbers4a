Aula 00 — Instalando o pixi e adquirindo a imagem CBERS-4A via STAC

Preparando o ambiente Python, conhecendo as bibliotecas e baixando a imagem por API

Autor

Data de Publicação

O que vamos aprender

Seja muito bem-vindo(a) à primeira aula dessa mini série!

Nesta aula, você vai preparar o ambiente Python que roda todas as aulas do curso: a correção atmosférica do CBERS-4A (TOA e BOA), a remoção de nuvens com o OmniCloudMask e a super-resolução do Sentinel-2 com o SEN2SR.

Um “ambiente” é uma caixa isolada com uma versão do Python e um conjunto de bibliotecas fixas — que permite você gerenciar tudo de forma organizada, sem conflitos e sem mexer alterar arquivos do seu sistema.

Para montar esse ambiente vamos usar o gerenciador de ambientes pixi. Ele lê um arquivo chamado pixi.toml (que já vem no repositório do curso), baixa o próprio Python e todas as bibliotecas na versão certa, e registra tudo num arquivo pixi.lock. Esse pixi.lock é o que garante que o ambiente da sua máquina seja idêntico ao que utilizei no vídeo.

NotaDúvida para nerds: Por que pixi? E não Miniforge/conda ou “pip” pelo terminal?

Esta sequência de aulas tem uma combinação que nenhuma ferramenta sozinha resolve bem no Windows:

  • A correção atmosférica BOA depende do programa Py6S, e o coregistro depende do GDAL. Esses binários, no Windows, só funcionam corretamente com conda-forge.
  • Os modelos de aprendizado profundo (omnicloudmask, sen2sr, mlstac) só existem no PyPI (o repositório do pip).

O pixi une os dois mundos — conda-forge e PyPI — num único arquivo e num único pixi.lock. Na prática, possibilita que você instale todas as bibliotecas no seu computador de maneira prática e sem preocupações, já que esse ambiente foi testado previamente e está pronto para uso, evitando que você precise rodar comandos manualmente e instalar diferentes versões, que podem te gerar incompatibilidades.

As principais bibliotecas do ambiente são: numpy, pandas, geopandas, rasterio, matplotlib, py6s (BOA), arosics (coregistro), torch, omnicloudmask, sen2sr e cubo. Você não precisa instalar nada disso à mão: o pixi.toml já lista tudo.

Passo 3 - Baixando a imagem CBERS-4A via API STAC

O STAC (SpatioTemporal Asset Catalog, ou Catálogo de Ativos Espaço-Temporais) é um site que organiza imagens de satélite de diversos provedores, incluindo o Brazil Data Cube (BDC - do INPE) que fornece as imagens CBERS-4A. Graças ao STAC, você pode “pré-processar” a imagem antes de baixá-la, como iremos fazer nesse tutorial.

DicaO que vamos fazer?

Nós vamos baixar uma imagem CBERS-4a do sensor WPM, com uma área de interesse (AOI) definida para a área urbana e o horto florestal de Rio Claro/SP. Vamos identificar a cena de interesse, filtrar a data e baixar as bandas espectrais (Banda 0 (PAN), Banda 1 (BLUE), Banda 2 (GREEN), Banda 3 (RED), Banda 4 (NIR)) já recortadas para nossa área em formato GeoTIFF.

Ao fazer isso, baixamos diversas bandas espectrais de uma só vez, já recortadas para a área de interesse, economizando tempo e espaço em disco.

Todo o código abaixo está na pasta colab/00_aquisicao_cbers.ipynb. Você pode rodá-lo de duas formas:

  • Local (recomendado): com o ambiente já pronto, rode pixi run lab, abra o notebook e execute célula a célula. Os arquivos caem direto em data/raw, que é onde a Aula 01 vai procurar.
  • Colab: clique no botão acima. A primeira célula instala as bibliotecas na sessão; no fim, baixe os GeoTIFFs (ou salve no seu Drive).

A escolha da cena é visual, pela miniatura (seção 3.5) e pela pré-visualização da AOI (seção 3.6) — nós iremos fazer a detecção de nuvem na Aula 02.

3.5 Buscando e escolhendo a cena

A busca por bbox retorna toda cena cujo contorno cruza a AOI — inclusive as que só encostam numa quina e cobrem a sua área apenas com nodata. Por isso, depois de buscar, a gente filtra no olho (miniaturas) e por um diagnóstico na AOI.

def buscar_cenas(bbox, datetime_range, collection=COLLECTION, limite=None):
    """Busca cenas no STAC e devolve (lista_de_items, DataFrame com o resumo)."""
    busca = client.search(collections=[collection], bbox=bbox,
                          datetime=datetime_range, max_items=limite)
    items = list(busca.items())
    linhas = []
    for i, item in enumerate(items):
        props = item.properties
        linhas.append({
            "idx": i,
            "id": item.id,
            "data": str(props.get("datetime", ""))[:10],
            "orbita_ponto": f"{props.get('path', '?')}_{props.get('row', '?')}",
            "bandas": sum(1 for k in BANDAS if k in item.assets),
        })
    return items, pd.DataFrame(linhas)

As funções abaixo leem só a AOI de um arquivo remoto, opcionalmente decimada. Elas são usadas aqui, na pré-visualização (seção 3.6) e na exportação (seção 3.7) — então rode esta célula mesmo que você já saiba qual cena quer.

Funções de leitura da AOI (reprojetar_bounds, janela_da_aoi, ler_aoi) 
def reprojetar_bounds(bounds, de="EPSG:4326", para=None):
    t = Transformer.from_crs(de, para, always_xy=True)
    minx, miny = t.transform(bounds[0], bounds[1])
    maxx, maxy = t.transform(bounds[2], bounds[3])
    return (minx, miny, maxx, maxy)


def janela_da_aoi(src, bbox):
    """Janela (em pixels) do dataset para o bbox em EPSG:4326, limitada a cena.

    Cada asset e aberto separadamente: a PAN tem grade de 2 m e as MS de 8 m, e
    cenas de orbitas diferentes podem estar ate em zonas UTM diferentes.
    """
    bounds = reprojetar_bounds(bbox, "EPSG:4326", src.crs)
    janela = from_bounds(*bounds, src.transform).round_offsets().round_lengths()
    col_off = max(0, int(janela.col_off)); row_off = max(0, int(janela.row_off))
    col_fim = min(src.width, int(janela.col_off + janela.width))
    row_fim = min(src.height, int(janela.row_off + janela.height))
    if col_fim <= col_off or row_fim <= row_off:
        raise ValueError("A AOI nao intersecta o retangulo desta cena.")
    return Window(col_off, row_off, col_fim - col_off, row_fim - row_off)


def ler_aoi(href, bbox, max_dim=None, masked=True):
    """Le a AOI de um asset. Com max_dim, faz leitura decimada (economiza RAM)."""
    with rasterio.open(href) as src:
        janela = janela_da_aoi(src, bbox)
        altura, largura = int(janela.height), int(janela.width)
        if max_dim and max(altura, largura) > max_dim:
            fator = max(altura, largura) / max_dim
            out_shape = (max(1, int(altura / fator)), max(1, int(largura / fator)))
        else:
            out_shape = (altura, largura)
        dados = src.read(1, window=janela, out_shape=out_shape, masked=masked)
        transform = window_transform(janela, src.transform) * rasterio.Affine.scale(
            largura / out_shape[1], altura / out_shape[0])
        return dados, transform, src.crs

Com elas em mãos, dá para responder de graça uma pergunta que vale centenas de megabytes: a cena cobre mesmo a sua AOI? A busca por bbox usa o contorno da cena, e é comum uma cena aparecer no resultado com 0% de cobertura real — o retângulo dela cruza a AOI, mas ali só tem nodata.

def cobertura_da_aoi(item, bbox, max_dim=150):
    """% da AOI com dado valido nesta cena, a partir de uma leitura reduzida do azul."""
    azul, *_ = ler_aoi(item.assets["BAND1"].href, bbox, max_dim=max_dim)
    validos = np.ma.filled(azul.astype("float32"), 0) > 0
    return round(100 * validos.sum() / validos.size, 1)

NotaPor que não estimar a nuvem por limiar de brilho aqui

3.6 Pré-visualização em RGB

Antes de baixar tudo em resolução total, vale conferir a cena com uma composição colorida da AOI. O contraste é por percentil (2%–98%), ignorando o nodata.

Funções de visualização (stretch, preview_rgb) 
def stretch(array, low_pct=2, high_pct=98):
    dados = np.ma.filled(array.astype("float64"), np.nan)
    validos = dados[np.isfinite(dados) & (dados > 0)]
    if validos.size == 0:
        return np.zeros_like(dados)
    p_lo, p_hi = np.percentile(validos, [low_pct, high_pct])
    if p_hi <= p_lo:
        p_hi = p_lo + 1
    return np.clip((dados - p_lo) / (p_hi - p_lo), 0, 1)


def preview_rgb(item, bbox, max_dim=800, bandas=("BAND3", "BAND2", "BAND1"), titulo=None):
    canais = [ler_aoi(item.assets[b].href, bbox, max_dim=max_dim)[0] for b in bandas]
    rgb = np.dstack([stretch(c) for c in canais])
    plt.figure(figsize=(9, 9)); plt.imshow(rgb); plt.axis("off")
    plt.title(titulo or f"{item.id}\n{str(item.properties.get('datetime'))[:10]}")
    plt.tight_layout(); plt.show()
    return rgb

3.7 Exportando as bandas para data/raw

Agora lemos em resolução total e gravamos GeoTIFF preservando o dtype original (int16, DN), o nodata = 0, o CRS e o transform do recorte — com compressão deflate e tiling. Saem 5 GeoTIFFs (um por banda) + os XML de metadados de cada banda, todos em data/raw.

Aviso

A PAN é de longe a mais demorada (4× mais linhas e colunas que as MS). Numa AOI de 4 × 4 km: cada banda MS leva alguns segundos e a PAN pode levar ~45 s. Se a conexão com o INPE cair no meio, rode a célula de novo — o que já baixou é reaproveitado.

Funções de exportação (exportar_banda, exportar_xml, exportar_cena, empilhar) 
def exportar_banda(href, bbox, caminho_saida):
    with rasterio.open(href) as src:
        janela = janela_da_aoi(src, bbox)
        dados = src.read(1, window=janela)
        altura, largura = int(janela.height), int(janela.width)
        perfil = src.profile.copy()
        perfil.update(driver="GTiff", height=altura, width=largura, count=1,
                      transform=window_transform(janela, src.transform),
                      compress="deflate", predictor=2)
        if altura >= 512 and largura >= 512:
            perfil.update(tiled=True, blockxsize=512, blockysize=512)
        else:
            perfil.update(tiled=False); perfil.pop("blockxsize", None); perfil.pop("blockysize", None)
    with rasterio.open(caminho_saida, "w", **perfil) as dst:
        dst.write(dados, 1)
    validos = 100 * np.count_nonzero(dados) / dados.size
    mb = os.path.getsize(caminho_saida) / 1024**2
    print(f"  {os.path.basename(caminho_saida):55s} {dados.shape} {dados.dtype} | {validos:5.1f}% validos | {mb:6.1f} MB")
    return caminho_saida


def exportar_xml(item, asset, caminho_saida):
    chave = f"{asset}_xml"
    if chave not in item.assets:
        print(f"  ! asset {chave} nao existe nesta cena — pulando"); return None
    resposta = requests.get(item.assets[chave].href, timeout=120); resposta.raise_for_status()
    with open(caminho_saida, "wb") as f:
        f.write(resposta.content)
    print(f"  {os.path.basename(caminho_saida):55s} {len(resposta.content)/1024:21.1f} KB de metadados")
    return caminho_saida


def exportar_cena(item, bbox, prefixo, output_dir=OUTPUT_DIR, bandas=BANDAS, com_xml=True):
    saidas = {}
    print(f"Exportando {item.id}:")
    for asset, apelido in bandas.items():
        if asset not in item.assets:
            print(f"  ! asset {asset} nao existe nesta cena — pulando"); continue
        base = os.path.join(output_dir, f"{prefixo}_{item.id}_{asset}")
        try:
            saidas[asset] = exportar_banda(item.assets[asset].href, bbox, base + ".tif")
        except Exception as erro:
            print(f"  ! falhou em {asset} ({apelido}): {type(erro).__name__}: {erro}")
        if com_xml:
            try:
                cx = exportar_xml(item, asset, base + ".xml")
                if cx:
                    saidas[f"{asset}_xml"] = cx
            except Exception as erro:
                print(f"  ! falhou no XML de {asset}: {type(erro).__name__}: {erro}")
    return saidas


def empilhar(caminhos, caminho_saida, descricoes=None):
    with rasterio.open(caminhos[0]) as ref:
        perfil = ref.profile.copy()
    perfil.update(count=len(caminhos))
    with rasterio.open(caminho_saida, "w", **perfil) as dst:
        for i, caminho in enumerate(caminhos, start=1):
            with rasterio.open(caminho) as src:
                dst.write(src.read(1), i)
            if descricoes:
                dst.set_band_description(i, descricoes[i - 1])
    print(f"{caminho_saida}  ({len(caminhos)} bandas, {os.path.getsize(caminho_saida)/1024**2:.1f} MB)")
    return caminho_saida
